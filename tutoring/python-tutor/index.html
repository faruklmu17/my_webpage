Curriculum Roadmap

What Your Child Will Learn

A structured, industry-aligned Python roadmap designed to transform passive learners into confident software creators.

1. Core Syntax & Logic

Mastering the fundamental building blocks of Python programming through engaging, hands-on coding exercises.

  • Variables, Data Types & Type Casting
  • Conditional Statements (if/elif/else)
  • Loops (for & while loops)
  • Functions, Arguments & Return Values

2. Data Structures & OOP

Organizing complex data and writing clean, reusable, professional-grade code using Object-Oriented Programming principles.

  • Lists, Dictionaries, Tuples & Sets
  • Classes, Objects & Methods
  • Inheritance & Encapsulation
  • Error Handling & Debugging Strategies

3. Pygame & Arcade Development

Bringing code to life by building interactive 2D arcade games, graphics, and animations from scratch.

  • Game Loops & Frame Rates (FPS)
  • Sprite Animation & Movement Mechanics
  • Collision Detection & Physics
  • Sound Effects & Score Tracking Systems

4. Scripting & Automation

Writing real-world utility scripts that automate boring computer tasks, scrape web data, and interact with APIs.

  • Automated File & Folder Management
  • Web Scraping with BeautifulSoup
  • REST API Consumption (JSON handling)
  • Building Automated Alert Bots

5. AI & Modern API Integration

Connecting Python scripts to state-of-the-art Artificial Intelligence models to build smart, cutting-edge applications.

  • Connecting to OpenAI & LLM APIs
  • Building Custom Interactive Chatbots
  • Intro to RAG (Retrieval-Augmented Generation)
  • Deploying Apps with Gradio & Hugging Face

6. Professional Engineering Tools

Learning the exact same industry workflows, version control, and collaboration tools used by professional software engineers.

  • Git Version Control & GitHub Repositories
  • Writing Clean Docstrings & Unit Tests
  • Virtual Environments (venv) & Pip
  • Code Reviews & Pull Request Best Practices

Faruk Hasan teaches live online Python programming to kids and teens, with courses ranging from beginner Python fundamentals to APIs, AI development, databases, and full-stack projects. What age group is this Python tutoring designed for?

My 1-on-1 Python lessons are specifically tailored for students aged 9 to 18 (Grades 4–12). I also mentor adult beginners and career switchers looking for practical coding skills.

What kind of Python projects will my child build?

We follow a 100% project-based curriculum. Depending on their level, students build arcade games using Pygame, web scrapers, automated file organizers, interactive Discord/Telegram bots, and AI chatbots using OpenAI and Hugging Face APIs.

Does my child need prior programming experience to start Python?

No prior experience is necessary! Python is universally recognized as the best first programming language due to its readable syntax. We start at the absolute basics and advance at the student's individual pace.

How do virtual 1-on-1 Python sessions work?

Sessions are conducted live via Zoom. We utilize collaborative coding environments like Replit and VS Code Live Share, enabling real-time pair programming and instant debugging guidance.

How does the free 20-minute consultation work?

During our free intro call, we meet on Zoom to discuss your child's current tech experience, learning style, and goals. We map out a customized Python learning path with zero financial commitment or pressure.
