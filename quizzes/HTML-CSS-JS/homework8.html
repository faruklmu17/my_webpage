Lesson goal

What is the DOM?

The Document Object Model (DOM) is the browser's representation of an HTML webpage as a tree of nodes. JavaScript uses it to find elements, inspect their relationships, and change what appears on the page.

HTML — what the browser receives

<body>
  <h1 id="title">My Website</h1>
  <p class="message">Hello!</p>
  <button>Click Me</button>
</body>

DOM — how to picture it

document
└─ html
└─ body
　├─ h1 #title
　├─ p .message
　└─ button
Ask the student: Which part is the parent of the heading, paragraph, and button? What are those three elements to each other?
Answer: body is the parent; the three elements are siblings.
