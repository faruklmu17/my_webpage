Privacy Policy

ChatGPT Stats Overlay is designed to respect your privacy. All data is processed locally in your browser and is never sent to any external server.

Information We Collect

The extension stores the following data locally in your browser:

  • Active time spent on ChatGPT (today, week, month)
  • Session count and daily usage streak
  • User-entered top priority goal and deadline
  • User notes, scratchpads, and pinned snippets (if used)
  • Optional statistics from an imported conversations.json file (only if you choose to import it)

Information We Do NOT Collect

  • No chat messages or conversation content
  • No personally identifiable information (name, email, address, etc.)
  • No passwords, authentication tokens, or credentials
  • No financial or payment information
  • No location or IP address data

How Your Data Is Used

  • To display usage statistics inside the ChatGPT overlay
  • To show your top priority goal and countdown timer
  • To store your notes and snippets locally for convenience

Data Storage

  • All data is stored using Chrome’s local storage API
  • All data remains on your device
  • No data is transmitted to any server

Data Sharing

  • No data is sold, shared, or transferred to any third party
  • No analytics or advertising services are used

Optional Import Feature

  • Importing chat history is optional and user-initiated
  • Files are processed locally in your browser
  • No imported data is uploaded or shared

User Control

  • You can remove all stored data by uninstalling the extension
  • You can clear browser storage at any time

Changes to This Policy

If this policy changes, it will be updated on this page.

Contact

If you have any questions about this privacy policy, you may contact the developer via the Chrome Web Store listing.
