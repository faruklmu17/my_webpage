Welcome to the Python Sandbox

A few features that will make your life easier while coding:

Run your code Click the green Run button or press Ctrl + Enter (Cmd + Enter on Mac).
Smart autocomplete As you type, suggestions pop up automatically. Press Ctrl + Space to force them. Use arrow keys + Enter to accept.
Live documentation Highlight any suggestion (like random.choice) and a panel shows what the function does and what arguments it takes.
Function signatures Type an open paren — like print( — and a tooltip shows what arguments the function expects.
Error checking as you type A red squiggle appears under syntax mistakes before you even click Run.
Learning examples Use the 📚 Load Example dropdown to start with ready-made beginner programs.
Your code stays private Everything runs in your own browser. Nothing is sent to any server.
